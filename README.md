## Calculadora de Jutsus - Naruto

Projeto em **Java** que simula o uso de jutsus do universo de **Naruto**, calculando o **gasto de chakra** e o **número de jutsus** usados.

---

## Sobre o projeto

Este programa exibe um menu com 4 jutsus famosos:
-  Chidori
-  Rasengan
-  Amaterasu
-  Hiraishin

O usuário:
- Escolhe um jutsu,
- Decide se quer usar outro jutsu ou finalizar.

Ao final, o programa mostra:
- Quantos jutsus você usou,
- Quanto de chakra você gastou.

---

## Tecnologias usadas

- **Java** (versão 17 ou superior)
- **Terminal** (Eclipse)
